# Code of conduct

Contributors and maintainers are expected to communicate respectfully and keep technical discussion grounded in evidence. Critique code and ideas without attacking people. Harassment, discrimination, threats, impersonation and disclosure of another person's private information are not acceptable.

Use issues and pull requests for project work. Avoid spam, repeated promotional messages and deliberately disruptive discussion. Respect contributor time and do not imply a support obligation or response deadline.

Maintainers may edit or remove inappropriate content, close disruptive threads, or restrict participation. Explain moderation decisions when doing so does not expose private information. If reporting misconduct publicly would disclose sensitive information, request a private contact channel without including the sensitive details.
